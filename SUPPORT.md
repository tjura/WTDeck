# Support

## Before opening an issue

Please check the existing documentation first:

- [README.md](README.md)
- [docs/configuration.md](docs/configuration.md)
- [docs/troubleshooting.md](docs/troubleshooting.md)

## Where to ask for help

Use GitHub Issues for:

- bug reports
- feature requests
- setup problems
- support questions about the current development version

When reporting a problem, include:

- Windows version
- Stream Controller version
- what you expected to happen
- what actually happened
- any relevant logs or screenshots

## Security issues

Do not use public issues for vulnerability reports.

Follow [SECURITY.md](SECURITY.md) and report them privately to
`juratomasz@gmail.com`.

## Response expectations

WTDeck is maintained on a best-effort basis. There is currently no guaranteed
support SLA, live support channel, or enterprise support offering.

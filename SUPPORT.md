# Support

## Before opening an issue

Please check the existing documentation first:

- [README.md](README.md)
- [CONTRIBUTING.md](CONTRIBUTING.md)

## Where to ask for help

Use project issues for:

- bug reports
- feature requests
- support questions
- documentation gaps

When reporting a problem, include:

- what you expected to happen
- what actually happened
- steps to reproduce the problem, if known
- any relevant screenshots, notes, or examples

## Security issues

Do not use public issues for vulnerability reports.

Follow [SECURITY.md](SECURITY.md) and report them privately to
`juratomasz@gmail.com`.

## Response expectations

WTDeck is maintained on a best-effort basis. There is currently no guaranteed
support SLA, live support channel, or enterprise support offering.
